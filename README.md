# Friday Niite Freestyle: Refreshed (HTML5)

Psych Engine based FNF mod compiled to HTML5 / OpenFL.

## Play it

Once GitHub Pages is enabled, the game will be live at:

**https://playboyjusthegreat27.github.io/freestyle-html/**

### Enable GitHub Pages (one-time)

1. Go to the repo → **Settings** → **Pages**
2. Under **Source**, choose **GitHub Actions**
3. Save

The existing workflow (`.github/workflows/static.yml`) will automatically deploy every push to `main`.

## Local testing

Just open `index.html` in a modern browser (Chrome/Edge recommended).  
Note: some browsers block local file loading of the big JS – use a simple local server if needed:

```bash
npx serve .
```
